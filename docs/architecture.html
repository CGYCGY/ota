OTA Install Server — Architecture

Self-hosted Diawi replacement · upload a signed .ipa → HTTPS install page + QR → over-the-air install on iPhone. One Bun + Hono container, app-agnostic, multi-project.

CI · Bearer token Admin browser · session cookie iPhone / Safari · public, no auth

System & deployment

Request flows

Upload & publish

CI (Bearer) or admin (session) → same POST /upload

  1. Client sends the .ipa as multipart/form-data — CI with Authorization: Bearer <token>, or the admin form riding its session cookie.
  2. auth middleware accepts either: validateToken (SHA-256 hash lookup, stamps last-used) or verifySessionCookie. No match → 401.
  3. ipa.ts unzips, finds Payload/*.app/Info.plist (binary or XML) → bundle id, version, build, name. Not an IPA → 400.
  4. storage.ts mints an unguessable id and writes app.ipa, manifest.plist (manifest.ts), and meta.json (written last) under /data/<id>/.
  5. Returns JSON: install_url, parsed app metadata, and expires_at.

Install on device

iPhone · Safari · all endpoints public

  1. Open /i/:id in Safari — directly, or by scanning the QR, which encodes that page URL (scanners handle https far better than the raw itms link).
  2. GET /i/:id → storage.ts loads meta (missing/expired → friendly 404 + lazy delete) → views.ts renders the page + QR.
  3. Tap Install → itms-services://?action=download-manifest&url=…/manifest.plist.
  4. iOS fetches manifest.plist as text/xml — unauthenticated, absolute https url inside.
  5. iOS fetches app.ipa as application/octet-stream — unauthenticated.
  6. iOS installs — only if the IPA is ad-hoc signed and the device UDID is registered (Apple-side, not the server).

Storage layout

/data/                          # persisted volume
├── tokens.json                 # [{ id, label, hash, createdAt, lastUsedAt, revoked }] — never the secret
└── <id>/                        # id = 16 CSPRNG bytes (hex); unguessable IS the access control
    ├── app.ipa                  # served application/octet-stream
    ├── manifest.plist           # served text/xml, absolute https app.ipa url
    ├── meta.json                # uploadedAt (epoch ms) is the TTL anchor — not fs mtime
    └── icon.png                 # optional
🔒

Why the download path is public. iOS fetches the manifest and IPA itself during install and cannot attach a token — so /i/:id* must be unauthenticated. Security is the unguessable CSPRNG id + short TTL, never a login. Only the upload is gated. Treat any install URL as shareable until it expires.
